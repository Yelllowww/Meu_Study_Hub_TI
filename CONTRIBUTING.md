# Como contribuir

Obrigado pelo interesse! Este é um portfólio pessoal, mas sugestões são bem-vindas.

1. Abra uma **Issue** descrevendo a sugestão ou o problema;
2. Faça um **fork** e crie uma branch: `git switch -c docs/minha-sugestao`;
3. Use mensagens no padrão [Conventional Commits](https://www.conventionalcommits.org/pt-br/);
4. Abra um **Pull Request** preenchendo o template.

Veja o [Guia de Colaboração](04_Documentacao/Guia_de_Colaboracao.md).
