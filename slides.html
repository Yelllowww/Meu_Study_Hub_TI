Ciência da Computação · Turma A (Noturno)

O problema

  • Trabalhos espalhados entre pastas, e-mails e pen drives;
  • Nenhum histórico mostrando como eu evoluí;
  • Recrutadores não têm onde ver o que eu sei fazer.

→ Solução: um único repositório, organizado, versionado e público.

1 · Planejamento do repositório

Meu_Study_Hub_TI/
├── 01_Apresentacao_e_Perfil/
├── 02_Disciplinas_Atuais/
│   ├── Bootcamp_I/  (Atividades_e_Entregas · Anotacoes_e_Resumos)
│   └── + 6 disciplinas do semestre

├── 04_Documentacao/

Pastas numeradas · sem acentos · um README.md em cada pasta.

2 · Versionamento com Git

  • GitHub Flow: main estável + branches feature/ e docs/;
  • Conventional Commits: feat:, docs:, chore:…
  • Tags SemVer: v1.0.0 → v1.1.0 → v1.2.0, com Releases;
  • Pull Request com template e revisão antes do merge.

3 · Organização e documentação

  • README principal com badges, árvore de pastas, versões e como executar;
  • README em cada disciplina e projeto: objetivo, tecnologias, estrutura, uso;
  • Guias em 04_Documentacao: versionamento, colaboração, Pages e LinkedIn;
  • CHANGELOG, CONTRIBUTING e templates de Issue/PR.

4 · GitHub Pages

yelllowww.github.io/Meu_Study_Hub_TI

  • Site publicado direto da branch main;
  • Perfil, interesses, arquitetura, matriz de disciplinas e histórico de versões;
  • Estes slides também são uma página do site.

5 · Integração com o LinkedIn

  • Repositório público com link de compartilhamento;
  • Seção Projetos: Study Hub — Portfólio Acadêmico e Profissional;
  • Seção Em destaque + site nas informações de contato;
  • Post de lançamento do portfólio.
