# GitHub Pages

O site é servido diretamente da branch `main`, pasta raiz (`/`).

| Página | URL |
|---|---|
| Início | https://yelllowww.github.io/Meu_Study_Hub_TI/ |
| Slides | https://yelllowww.github.io/Meu_Study_Hub_TI/slides.html |

## Como foi ativado

1. **Settings → Pages**;
2. *Source*: **Deploy from a branch**;
3. *Branch*: `main` · pasta `/ (root)` → **Save**;
4. Após ~1 minuto o site fica disponível no endereço acima.

O arquivo `.nojekyll` desativa o processamento Jekyll, servindo os arquivos HTML exatamente como estão.
