# Integração com o LinkedIn

## 1. Link público do repositório

- Repositório: https://github.com/Yelllowww/Meu_Study_Hub_TI (público)
- Site: https://yelllowww.github.io/Meu_Study_Hub_TI/

## 2. Seção **Projetos**

Perfil → **Adicionar seção** → *Recomendado* → **Adicionar projetos**

| Campo | Preenchimento |
|---|---|
| Nome | Study Hub — Portfólio Acadêmico e Profissional |
| Descrição | Repositório versionado com Git que organiza minha produção no curso de Ciência da Computação: disciplinas, projetos e certificados, publicado com GitHub Pages. |
| Habilidades | Git · GitHub · GitHub Pages · Markdown · HTML · CSS · JavaScript |
| Associado a | Ciência da Computação |
| Mídia | Link do site + link do repositório |

## 3. Seção **Em destaque**

Perfil → **Adicionar seção** → *Recomendado* → **Adicionar em destaque** → **Adicionar um link** → cole o link do site.

## 4. Informações de contato e Sobre

- **Informações de contato → Site:** adicione o site (tipo *Portfólio*) e o GitHub;
- **Sobre:** finalize com “📂 Portfólio: yelllowww.github.io/Meu_Study_Hub_TI”.

## 5. Publicação

Crie um post anunciando o Study Hub com o link do site, a imagem dos slides e as hashtags `#GitHub #CienciaDaComputacao #Portfolio`.

## 6. Do GitHub para o LinkedIn

O [README de perfil do GitHub](https://docs.github.com/pt/account-and-profile/setting-up-and-managing-your-github-profile/customizing-your-profile/managing-your-profile-readme) (`Yelllowww/Yelllowww`) também traz o link do LinkedIn, fechando a integração nos dois sentidos.
