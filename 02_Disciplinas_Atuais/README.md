# 02 · Disciplinas Atuais

Cada disciplina tem sua própria pasta com o mesmo padrão interno:

```text
Nome_da_Disciplina/
├── README.md                 → ementa resumida e índice
├── Atividades_e_Entregas/    → trabalhos entregues (com data no nome)
└── Anotacoes_e_Resumos/      → resumos de aula em Markdown
```

## Matriz do Study Hub

| Semestre / Módulo | Disciplina | Tipo de material | Justificativa |
|---|---|---|---|
| 1º Módulo | **Bootcamp I** | Planejamento da arquitetura do Study Hub e entregas do projeto | Define a base de organização profissional para todo o curso |
| 1º Módulo | Sistemas em Tempo Real e Embarcados | Códigos de firmware, diagramas e relatórios de laboratório | Área de maior interesse; projetos práticos viram portfólio |
| 1º Módulo | Testes e Qualidade de Software | Planos de teste, casos de teste e scripts automatizados | Demonstra preocupação com qualidade — valorizado no mercado |
| 1º Módulo | Projeto Integrador | Documentação, código e apresentações do projeto em grupo | Evidencia trabalho em equipe e colaboração via Git |
| 1º Módulo | Segurança Digital | Resumos, checklists e laboratórios | Conecta redes/infra com boas práticas de segurança |
| 1º Módulo | Análise e Produção de Texto | Resumos e textos produzidos | Melhora a escrita da documentação técnica (READMEs) |
| 1º Módulo | Ética, Cidadania e Realidade Brasileira I e II | Resumos e reflexões | Base para atuação ética e responsável na profissão |
| 2º Módulo | *Disciplinas futuras* | Projetos práticos | A estrutura se repete a cada novo módulo |
