# Bootcamp I

**Carga horária:** 75h · **Projeto integrador:** Study Hub

| Fase | Entrega | Status |
|---|---|---|

| 2 · Construção | Repositório versionado no GitHub + GitHub Pages + LinkedIn + vídeo | ✅ |
| 3 · Lançamento | Portfólio digital completo | ⏳ |
