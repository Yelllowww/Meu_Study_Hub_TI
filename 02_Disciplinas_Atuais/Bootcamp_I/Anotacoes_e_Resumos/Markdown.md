# Markdown — Resumo

| Elemento | Sintaxe |
|---|---|
| Títulos | `# H1`, `## H2`, `### H3` |
| Negrito / itálico | `**negrito**`, `*itálico*` |
| Lista | `- item` ou `1. item` |
| Checklist | `- [ ] tarefa` / `- [x] feita` |
| Link | `[texto](url)` |
| Imagem | `![alt](caminho.png)` |
| Código | `` `inline` `` ou blocos com três crases |
| Tabela | `| A | B |` + `|---|---|` |

**Um bom README responde:** o que é? por que existe? como usar? como contribuir? qual a licença?
